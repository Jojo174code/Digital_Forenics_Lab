# Digital_Forenics_Lab


🔍 Lab 13.8: Digital Forensics (Zybooks)
This lab introduces core concepts in digital forensics, focusing on creating and analyzing forensic images from compromised systems. The tasks involve using FTK Imager and Autopsy to inspect and report on a Windows Server 2022 environment.

🧠 Learning Objectives
--Create a forensic bit-for-bit copy of a system

--Convert dd image format to E01 using FTK Imager

--Analyze file systems using Autopsy

--Recover and inspect deleted or hidden data

--Generate a formal forensics report

🖥️ Environment
--VM Used: ZyWin01 (Windows Server 2022)

✅ Tasks Completed
1) Converted a dd image to .E01 using FTK Imager

2) Analyzed the file system with Autopsy

3) Recovered data and generated a forensic report using Autopsy
